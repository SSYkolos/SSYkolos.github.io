02

How I build

  1. Deterministic

    The APIs use no AI. The same file always gives the same result, and every number can be traced back to the input.

  2. Private by default

    Uploaded files are processed in memory and never stored. The browser extension runs entirely on your computer.

  3. Tested on real files

    Public samples from real banks, thousands of deliberately damaged drawings, live runs in four Google Maps languages.

  4. Honest about limits

    Every product page lists what it does not support yet, before you spend time integrating it.
