```bash
curl -X POST "https://<host>/v1/convert?profile=de" -H "Content-Type: application/xml" --data-binary @old.xml -o new.xml
```

The converted file is returned only after it has passed the 2019 schema and the SEPA rules.
`return_report=true` returns JSON instead, with the list of changes and the validation report.
Files go in the raw body, as base64 (`Content-Transfer-Encoding: base64`) or as a multipart field `file`, up to 10 MB.
