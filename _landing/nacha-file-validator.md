| Area | Checks |
|---|---|
| File | 94-character records, printable ASCII, record order, padding to blocks of 10; CRLF, LF and unbroken files are read alike |
| File header | constants, immediate destination (routing check digit), immediate origin (routing number or `1` + EIN) |
| Batches | service class 200 / 220 / 225 and that it matches the entries, SEC code, required company fields |
| Dates | effective date valid, not in the past, not a weekend or Federal Reserve holiday (warnings) |
| Entries | transaction codes, prenotes and zero-dollar entries with amount 0, routing check digit (3-7-1), account number, Same Day ACH limit $1,000,000 (warning) |
| Addenda | addenda indicator, count, type, sequence numbers |
| Trace numbers | unique and ascending |
| Totals | batch and file control: entry and addenda count, entry hash (last 10 digits), debit and credit totals, block count, matching header fields |
| SEC rules | TEL debits only (except REVERSAL), WEB payment type code, 2026 descriptions: PAYROLL for PPD wage credits, PURCHASE for WEB purchase debits (warnings) |
| Optional | balanced batches |
